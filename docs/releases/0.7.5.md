# Shared Tasks 0.7.5

Shared Tasks 0.7.5 shows the Apple Reminders bridge for what it is in your
device list, lets you disconnect it, and labels it experimental. For
catalog users updating from 0.7.4.

**Requires Obsidian 1.13.4 or later**, as 0.7.4.

The Markdown format of your notes and the sync protocol are unchanged. It
uses the OpenLFCP SDK 0.5.2, as 0.7.4.

## What changed since 0.7.4

- **Service devices say what they are.** In "Your devices…", a service
  device (a bridge or bot, such as the Apple Reminders bridge) has a line
  saying so. Its action is **Disconnect…**: the same removal as for a device
  of yours, with what happens said plainly. It stops syncing these sections
  for good; what it already wrote stays, so a Reminders bridge's reminders
  stay in Apple Reminders as yours.
- **Approving a service links to the bridge's runbook**: how the Reminders
  bridge runs, and how to disconnect it later.
- **The Reminders bridge is experimental.** The device list, the Disconnect
  dialog and the approve dialog say so: it is a tech preview, a separate
  app you run from the Terminal on a Mac
  ([openlfcp/bridge](https://github.com/openlfcp/bridge)).
- **README.** "Your devices" now describes what ships, and a new section
  introduces the Apple Reminders bridge.

## Install and upgrade

From Settings → Community plugins → Updates. Nothing to migrate.

By hand: put `main.js`, `manifest.json` and `styles.css` from the release
page into `<vault>/.obsidian/plugins/shared-tasks/` and compare them with
these checksums.

Built by CI from the commit the tag `0.7.5` points to; the release page
carries a build provenance attestation: `gh attestation verify main.js
--repo openlfcp/obsidian`.

## Rolling back to 0.7.4

Install 0.7.4 over 0.7.5. The data format is the same. 0.7.4 lists a
service device like a device of yours, with **Remove device…**; removing it
has the same effect as Disconnect.

## Known limits

The limits in [0.7.4](0.7.4.md#known-limits) still apply.

- **The Reminders bridge is a tech preview.** It is not part of this plugin
  and has no installer: it is set up and run from the Terminal, on a Mac.
