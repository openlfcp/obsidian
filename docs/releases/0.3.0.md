Shared Tasks 0.3.0 (beta): share and insert many tasks at once.

## New

- **"Share selected tasks".** Shares every task line you selected. With
  nothing selected, it shares the tasks under the heading at the cursor,
  down to the next heading of the same or a higher level. You pick the
  collaboration once; each task becomes a shared task of its own, nested
  ones included, and all their `lfcp-ref` comments are written in one go.
  Tasks already shared are skipped, and tasks with a broken `lfcp-ref` or
  without a title are left alone. One notice says how many were shared,
  skipped and refused.
- **"Insert all tasks from collaboration".** Places, at the cursor, every
  task of a collaboration that this note does not show yet, in the order
  they were created. Run it again later to add only what is new.
- Each command handles at most 200 tasks; above that it changes nothing
  and says so. The pick dialog reminds you that everyone invited to a
  collaboration sees every task in it.

## Changed

- A newly shared task records when it was created (`created_at`), which
  is how "Insert all" keeps the order of the note it came from. Tasks
  shared with earlier versions have no creation time and are inserted
  first.

A shared list or section is not itself shared: its order, its heading and
tasks added to it later stay local in each note.

## Install and upgrade

With [BRAT](https://github.com/TfTHacker/obsidian42-brat)
(`openlfcp/obsidian`), which updates to 0.3.0 by itself, or by hand from
`shared-tasks-0.3.0.zip` on the release page. Needs Obsidian 1.13.1 or
later. Your identity, collaborations and settings are kept.
