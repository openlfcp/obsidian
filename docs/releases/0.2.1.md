Shared Tasks 0.2.1 (beta): a patch release before the plugin goes into
Obsidian's community directory.

## Fixed

- **A collaboration the server refuses for good now says so.** When the
  server no longer hosts a collaboration (it was purged, or the server
  was restored from an older backup) or your access was removed, you get
  one notice: "Shared Tasks: "<name>" stopped syncing. Not hosted by
  <server>: …". "Resource status" shows the reason in the Sync row
  instead of "Sync error: retrying". Shared Tasks stops retrying it;
  restarting Obsidian asks the server again.
- **A collaboration created offline starts syncing once it is hosted**,
  without a restart.
- The invitation preset is written in sentence case: "Read + write".
- Code clean-ups for Obsidian's plugin review (the official lint rules
  report no errors). No change in behaviour.

## Install and upgrade

As for [0.2.0](0.2.0.md): with BRAT (`openlfcp/obsidian`), which updates
to 0.2.1 by itself, or by hand from `shared-tasks-0.2.1.zip`. Needs
Obsidian 1.13.1 or later. Your identity, collaborations and settings are
kept.
