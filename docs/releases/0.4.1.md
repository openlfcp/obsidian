Shared Tasks 0.4.1: a fix for edits to shared sections that could be lost.
Update soon.

**Requires Obsidian 1.13.4 or later**, as 0.4.0.

## Fixes

- **An edit to a shared section could be silently lost after a restart.**
  When Obsidian started (or Shared Tasks was re-enabled), the same shared
  section could be opened twice at once. Your edits then went to a copy
  that nothing read: the section showed as current, your change (for
  example a task renamed while offline) disappeared from the note, and
  your collaborators' later changes never appeared. 0.4.1 opens a section
  only once, however many parts of the plugin ask for it at the same time.
  The same fix applies to collaborations of tasks (from 0.3).
- **An edit could be undone on your device after it was saved.** If
  sending a saved change failed (for example the connection dropped at
  that moment), the change could be taken back out of the section on your
  device while it still went out to your collaborators. SDK 0.2.1 keeps a
  change once it is saved.
- **A section given up while it was opening is closed.** A section whose
  creation was given up while it was still opening no longer stays open
  in the background.
- **Nothing keeps running after Shared Tasks is disabled.** Disabling the
  plugin while it was still opening its sections at start could leave a
  connection behind; it no longer does.

## Under the hood

- The TypeScript SDK is `@openlfcp/*` 0.2.1 (exact versions, from npm with
  provenance): a section batch the durable store has committed is not
  rolled back when a step after the commit throws.
- Spec `mvp-0.2-baseline.12`; the project server runs the reference server
  0.3.2, unchanged by this release.
- A live test with two plugins on the reference server covers an edit kept
  across a restart and the server's absence, and a send that fails after
  the commit.

## Install and upgrade

From Community plugins (Settings → Community plugins → Updates), with BRAT
(`openlfcp/obsidian`), or by hand: put `main.js`, `manifest.json` and
`styles.css` from the release page into
`<vault>/.obsidian/plugins/shared-tasks/`. Your identity, collaborations and
settings are kept.
