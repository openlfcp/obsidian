Shared Tasks 0.3.4 (beta): a security fix. Update soon.

**Requires Obsidian 1.13.4 or later**, as 0.3.3.

## Fixes

- **One malicious change could stop a collaboration on your device.**
  Someone with write access to a collaboration could send a change that
  made the collaboration's shared state unusable on the devices that
  received it: they no longer took that person's next changes, and after
  the next start of Obsidian the collaboration no longer opened. Your notes
  were never changed, and other collaborations were not affected. 0.3.4
  refuses such changes before they reach the shared state, and if a
  received change ever fails inside the sync engine, the collaboration
  keeps the state it had before that change.

## Under the hood

- The TypeScript SDK is `@openlfcp/*` 0.1.5 (exact versions, from npm with
  provenance): it refuses a change that makes an Automerge table
  (SHARED-OBJECTS-PROFILE-01 §11.4 R10), and rolls the document back when
  a change aborts in the engine (differential-fuzzing defect D1).
- Spec `mvp-0.1-baseline.10`, server 0.3.0.

## Install and upgrade

From Community plugins (Settings → Community plugins → Updates), with BRAT
(`openlfcp/obsidian`), or by hand: put `main.js`, `manifest.json` and
`styles.css` from the release page into
`<vault>/.obsidian/plugins/shared-tasks/`. Your identity, collaborations and
settings are kept.
