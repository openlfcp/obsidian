Shared Tasks 0.2.0 (beta): share tasks between Obsidian vaults, end-to-end
encrypted, without uploading your notes. Built on OpenLFCP.

## What's new

- **New name.** The plugin is now **Shared Tasks**, plugin ID
  `shared-tasks` (it was "OpenLFCP", `openlfcp`, in 0.1.0). Its commands,
  notices and status bar say "Shared Tasks:" too, e.g. "Shared Tasks:
  task shared."; OpenLFCP remains the name of the protocol and of the
  project that runs the public server.
- **A default server.** "Create collaboration" now offers the OpenLFCP
  project's public server, `wss://sync.openlfcp.org/v1/ws` (beta), with a
  line saying who runs it and links to its
  [privacy note](https://github.com/openlfcp/.github/blob/main/docs/operations/sync-server-privacy.md)
  and [terms](https://github.com/openlfcp/.github/blob/main/docs/operations/sync-server-terms.md).
  The server sees metadata, never your task text. Use your own server
  by changing Settings → Shared Tasks → "Default server". A collaboration
  stays on the server it was created on.

## Install

With [BRAT](https://github.com/TfTHacker/obsidian42-brat): "Add Beta
plugin" → `openlfcp/obsidian`. Or by hand: unzip `shared-tasks-0.2.0.zip`
into `<vault>/.obsidian/plugins/`, then enable "Shared Tasks" in Settings →
Community plugins. Needs Obsidian 1.13.1 or later. Tested on desktop;
mobile is not tested yet.

## Upgrading from 0.1.0 ("OpenLFCP")

The new ID makes Obsidian treat Shared Tasks as a new plugin. Your
identity and collaborations stay: they are kept per vault on this device,
not in the plugin's folder.

1. Disable "OpenLFCP" and remove it (Settings → Community plugins), or
   delete `<vault>/.obsidian/plugins/openlfcp/`. Never run both: whichever
   starts second stops writing, with "Another OpenLFCP instance…" (0.1.0)
   or "Another Shared Tasks instance is using this vault's local state."
   (0.2.0).
2. Install Shared Tasks as above.
3. Optional: copy `data.json` from `.obsidian/plugins/openlfcp/` into
   `.obsidian/plugins/shared-tasks/` to keep the ref placement and default
   server settings, and set your hotkeys for the commands again (they now
   start with "Shared Tasks:").
