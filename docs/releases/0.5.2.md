# Shared Tasks 0.5.2

Shared Tasks 0.5.2 answers the automated review of the Obsidian community
directory: the plugin's code now passes Obsidian's own lint rules without
warnings. For catalog users updating from 0.5.1; nothing changes in how you
share tasks.

**Requires Obsidian 1.13.4 or later**, as 0.5.1.

The Markdown format of your notes and the sync protocol are unchanged.

## What changed since 0.5.1

- **The command "Open Shared Tasks pane" has a new ID, `open-pane`** (it
  was `open-shared-tasks-pane`), because the community review asks that a
  command ID not repeat the plugin ID. The command name is the same.
- **Elements, timers and type checks work the Obsidian way.** The plugin
  builds its interface with Obsidian's own element helpers and uses the
  window's timers, which is what pop-out windows expect.
- **A damaged section marker is marked with a solid warning underline**
  instead of a wavy one, in the same warning color. The line keeps its
  height.
- **The developer pane prototype is removed.** It never shipped in a
  release build. An old `data.json` that still has the
  `developerPanePrototype` key is read as before and the key is ignored.

## Install and upgrade

From Settings → Community plugins → Updates. Nothing to migrate: identity,
keys, shared sections and queued edits are kept.

If you set a hotkey on "Open Shared Tasks pane", set it again under
Settings → Hotkeys: a hotkey belongs to the command ID, and the ID changed.

By hand: put `main.js`, `manifest.json` and `styles.css` from the release
page into `<vault>/.obsidian/plugins/shared-tasks/` and compare them with
these checksums.

Built by CI from the commit the tag `0.5.2` points to; the release page
carries a build provenance attestation: `gh attestation verify main.js
--repo openlfcp/obsidian`.

## Rolling back to 0.5.1

Install 0.5.1 over 0.5.2 (BRAT: choose version 0.5.1 for
`openlfcp/obsidian`, or put 0.5.1's three files into the plugin folder).
The data format is the same; a hotkey set on the new command ID has to be
set again.
