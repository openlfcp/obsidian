Shared Tasks 0.3.1 (beta): a smaller plugin that builds from a clean clone.

This release answers the community directory's automated review. Nothing
changes in how you share tasks.

## Changed

- **`main.js` is 1.9 MB instead of 5.6 MB**, under Obsidian Sync's 5 MB
  limit. The bundle is minified, and Automerge's wasm is stored deflated
  and inflated when the plugin loads (the same bytes as before). The
  licences of the bundled third-party packages are at the end of the file.
- **Settings use Obsidian 1.13's declarative settings**, so they show up
  in the settings search.
- **Lighter start-up scan.** The plugin looks for `lfcp-ref` comments
  through Obsidian's content cache, and reads in full only the notes that
  have one.
- Timers, the clipboard and the browser storage API are used through
  `window`, so they also work in popout windows.
- The README has a new section, "What the plugin accesses".

## Release and build

- The release has exactly three files: `main.js`, `manifest.json` and
  `styles.css` (no zip). Each carries a signed build provenance
  attestation; check it with
  `gh attestation verify main.js --repo openlfcp/obsidian`.
- The TypeScript SDK now comes from npm (`@openlfcp/*` 0.1.1, exact
  versions), so `pnpm install --frozen-lockfile && pnpm build` works in a
  clean clone, without a sibling `sdk-ts` checkout.

## Install and upgrade

With [BRAT](https://github.com/TfTHacker/obsidian42-brat)
(`openlfcp/obsidian`), which updates to 0.3.1 by itself, or by hand: put
`main.js`, `manifest.json` and `styles.css` from the release page into
`<vault>/.obsidian/plugins/shared-tasks/`. Needs Obsidian 1.13.1 or later.
Your identity, collaborations and settings are kept.
